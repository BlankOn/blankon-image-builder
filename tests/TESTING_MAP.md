# Testing scope

- `tests/lib.sh:fixture_init` copies entrypoints into a temporary workspace, creates synthetic sources/configuration, stubs `lb`, mounts, `curl`, and `zsyncmake`, and installs fail-closed Podman, Docker, user-namespace, and sudo guards. `tests/build-iso.sh`, `tests/cache.sh`, and `tests/purge.sh` exercise publication/checksums, local Git clone/branch/commit handling, cache reuse/invalidation, lock contention, and unsafe-path refusal without building a real ISO. The container build fixture runs without notification credentials and asserts that no curl notification occurs.
- `tests/podman-wrapper.sh` retains its historical suite name but tests the normal `build-iso` and `purge-iso` entrypoints with fake Podman. Coverage includes local/remote arguments, explicit rootless user mapping, read-only source binds, canonical root/overlap/symlink refusal, safe output and lock paths beneath `BUILD_LOCAL`, shared locks, and purge mount boundaries. Fake curl decodes host-only notification payloads and checks synthetic-token isolation and transport failures. `tests/podman-build-lock.sh` also verifies lock recovery after process termination and inner lock-held dispatch.
- `tests/namespace-dispatch.sh` uses a copied temporary entrypoint and synthetic `.env`, with fake `unshare` and fail-closed Podman/curl commands. `tests/mount-cleanup.sh` stubs mount listings and unmounts to check deepest-first workspace cleanup without unmounting a source tree. These fixtures do not establish live kernel namespace or mount behavior.
- `tests/seccomp-profile.sh` retains its suite name but now checks the entrypoints' rootless identity, default-seccomp, capability, and namespace flags using static source assertions. The obsolete Moby profile generator and its image copy are removed. Actual fake-runtime argument dispatch is covered by `tests/podman-wrapper.sh` and `tests/namespace-dispatch.sh`. `tests/patch-live-build-sysfs.py` exercises the version-checked image helper patch using temporary input files, not live sysfs mounts.
- `build-iso:run_host_podman_build` coordinates separate configuration, path-validation, locking, image-build, container-run, and host-notification phases. `purge-iso:run_host_purge` and `run_container_purge` separate host dispatch from cache validation/removal. `tests/purge.sh` verifies that an absent cache is a no-op even with an inherited or stale `VALIDATED_PACKAGE_CACHE`, and that unrelated temporary sentinel data survives repeated validation. Suite entrypoints run independently; build and lock suites no longer invoke other suites implicitly.
- `.github/workflows/build-iso.yml` runs all nine fixture suites once in `fixtures`, replacing the separate cache/purge workflows. `resolve-source` validates the upstream `dummy-sinambung` branch (variant `ci`) by default, or `variant-gnome` (variant `gnome`) for the manual `gnome` profile, and provides one resolved SHA to both local and remote matrix jobs. Both build modes require successful fixtures and source resolution. Push/PR and manual runs define real ISO builds; the testing branch must be committed and published to `BlankOn/blankon-live-build` first, with no embedded-fixture fallback. The selected upstream branches remain mutable between workflow runs. Neither profile boots an ISO.
- CI installs and checks rootless Podman and uses the production `Dockerfile` through the normal entrypoints without a Compose override or separate Podman workflow. Shared setup creates `BUILD_LOCAL` and its host lock parent for both modes; remote mode clones the selected upstream snapshot under `workdir` without a source bind. CI checks published artifacts, checksums, selected output UID/GID ownership, real package-cache save/restore hashes, and purge preservation for the small profile. `tests/e2e/verify-package-cache.sh` sources `/usr/local/bin/build-iso` inside the Podman image while the host holds the package-cache lock. CI does not verify ISO structure, complete package manifests, or that live-build consumed a restored cache; fixture and static success are not real ISO acceptance evidence.
